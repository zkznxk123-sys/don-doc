## 2. 북극성 · Tagline · Mission

### 북극성 (North Star, 2026-07-06 확정)
> **태도 한 줄**: 복잡한 투자, 단순하게.
> **정의(풀메시지)**: 현금흐름으로 만든 여유자금을 단단한 자산으로 꾸준히 옮기는 것.
> **리듬(기억용)**: 본다 → 남긴다 → 옮긴다.

돈Doc은 "자산 관리 시스템"(기능)이 아니라 **투자를 어렵게 만드는 것에 대한 반항**(태도)이다. 나이키 "Just Do It"이 운동화가 아니라 태도를 팔듯, 돈Doc의 북극성은 태도다.

**투자의 재정의** — 여기서 "투자"는 종목 고르기·매매가 아니라 **"현금흐름으로 만든 여유자금을 단단한 자산으로 꾸준히 옮기는 습관"**이다. 축적·이동(안전)이지 추천·타이밍(유사투자자문)이 아니다.

**정의 = 제품의 4단계**:

| 문장 beat | 뜻 | 기능 |
|---|---|---|
| 현금흐름을 통해 | 버는 흐름을 본다 | 현금흐름 관리 |
| 만들어낸 여유자금 | 남는 돈을 만든다 | 예산·저축률 |
| 단단한 자산으로 | 질 좋은 자산으로 | 자산 관리 + 공모주(취득 채널) |
| 꾸준히 옮기는 것 | 습관으로 | 매달 10분 정리 |

**2층 브랜드 아키텍처** — 우산(투자, 재정의) + 제품별 설명:

```
[우산·태도]   복잡한 투자, 단순하게 (= 여유자금을 단단한 자산으로 꾸준히)
   ├─ 자산 관리 버전  흐름·여유·현황을 한눈에 (투자의 수단)  → "가장 쉬운 자산 관리"
   └─ 공모주 버전     단단한 자산 취득 채널 하나            → "가장 쉬운 공모주"
```

- 우산 단어 = **"투자"(재정의)**. 자산 관리는 투자를 잘하기 위한 인프라 → 자산 버전도 우산 안에 정합.
- **타깃 진화**: "가계 부부" → **"자산을 쌓으려는 사람"**으로 상위 프레임 이동(부부는 그 안의 세그먼트).
- ⚠️ **컴플라이언스**: ①증권사 임직원의 '투자' 브랜드는 회사 준법 프로파일이 오르니 확인 필요, ②"투자=단단한 자산 축적" 정의를 카피로 계속 가르쳐야. 종목 추천·비례 유불리 예측은 절대 금지.

### Primary Tagline (자산 버전 설명)
> **가장 쉬운 자산 관리 — 흩어진 자산을 한 화면에.**

- SEO description, OG image, App Store, 채널 bio에 사용. **랜딩 Hero엔 미노출** — Hero는 북극성 H1이 대문(§14). Threads bio 정본과 1:1 일치.
- 영문: *The easiest way to manage your assets — scattered assets, one view.*

### One-liner — ⚠️ 강등 (2026-07-10)
> ~~돈 관리는 똑똑하게, 관계는 더 돈독하게.~~

- 가족 유대 시절 원라이너. 북극성(「복잡한 투자, 단순하게」) 전환 후 실사용 0 → **참고 카피로 강등, 신규 산출물에 쓰지 말 것**. /about 이름 섹션도 「돈 + Doc = 돈독」 풀이로 교체(`3fa474b`). 관계 레이어는 이름 3-Layer(§3)와 /about "그래서, 돈독" 카드가 담당.

### Mission
> 복잡하게 흩어진 자산을 가장 쉽게 한 화면으로 통합하는 도구. 혼자 써도 충분하고, 필요하면 가족·동업자와 선별적으로 공유한다.

## 5. Voice & Tone

| 상황 | 톤 | 예시 |
|---|---|---|
| Hero / 헤드라인 | Confident, 짧음 | "복잡한 투자, 단순하게." (북극성 · 랜딩 H1 정본) |
| 본문 설명 | Clear, 존댓말, 단정 | "흩어진 자산을 한 화면에서 단단하게." |
| CTA 버튼 | 동사 원형, 간결 | "무료로 시작하기", "데모 체험하기" |
| 빈 상태 | Warm, 부드러움 | "아직 기록이 없어요." |
| 에러 | 사실, 해결책 | "연결이 끊어졌어요. 다시 시도해 주세요." |
| 금액 표기 | tabular 그로테스크(hero 크게, 정밀값 서브) | 10.1억 / ₩1,012,212,539 |

**북극성 목소리 4원칙** (2026-07-06):
1. **짧고 단정** — 문장 길면 진 거다. 명령형·반문형 OK ("돈, 어렵게 하지 마")
2. **반항적이되 친근** — 건방지지 않게, 위트 한 스푼 (JDI의 "그냥 해" 결)
3. **기능 나열 금지** — "5종 자산 통합…" 대신 태도로 말한다
4. **전문용어·번역체 금지** — 한국어 Sunny 7규칙(CLAUDE.md)과 정합

- **IN**: 단순 · 속도 · 복잡함 제거 · 위트  |  **OUT**: 투자 권유(컴플라이언스) · 기능 자랑 · 럭셔리한 무게 · 겁주는 금융 톤
- **Golden rule**: 북극성은 **단순함(태도)**. 복잡함을 걷어내면 시간·여유·더 나은 판단이 따라온다.

## 6. 시각 정체성 — Solid Modern

**한 줄**: 딥 포레스트 다크 + 강한 골드 + 숫자가 주인공. 대담하고 단단하고 요즘스럽다.

계보: Citium Wealth(다크그린+골드+오빗 아크·프리미엄) 팔레트 + Montera(글래스 3D 깊이·숫자 히어로) 에너지 + Arc/Vercel/Bloomberg(단단한 tool·고대비)의 합성.

**정체성 3요소**
1. **숫자가 히어로** — 순자산·자산 숫자가 모든 화면의 주인공. 가장 크게, tabular로, 흔들림 없이.
2. **단단·꾸준 > 반짝·hype** — 고대비·솔리드·차분. 움직임은 "쌓임/궤도"로만.
3. **대담한 단순함** — 과감한 여백·초점 하나·짧은 카피. 요소를 줄이되 브랜드 앵커(골드)는 남긴다.

## 7. Color — 듀얼 모드

정체성은 하나, 모드는 둘. **랜딩·마케팅·공모주(프로암) = 다크 우선 / 데일리 앱 = 라이트·다크 토글**. CSS 변수 = `app/globals.css`(`:root` 라이트 / `.dark` 다크). 랜딩 상수 = `components/marketing/landing/tokens.ts`의 `SM_*`.

### 다크 (마케팅·프로)
| 토큰 | 값 |
|---|---|
| surface | `#182A24` 딥 포레스트 |
| panel | `#1F2E28` / raised `#26362F` |
| ink | `#F4F1E9` 웜 화이트 / dim `rgba(244,241,233,.62)` |
| **gold** | **`#C9A54A`** accent·CTA·숫자·차트 |
| hairline | `rgba(201,165,74,.20)` |

### 라이트 (데일리)
| 토큰 | 값 |
|---|---|
| surface | `#F5F3EE` 하이키 페이퍼 / card `#FFFFFF` |
| ink | `#182A24` 딥 포레스트 잉크 |
| **gold** | **`#B88A2A`** (라이트 대비 확보) |

### 시맨틱·규칙
- **상승·수입** = 골드 또는 세이지 `#4E7A5F`(절제). **하락·지출** = 테라코타 `#C0553D`.
- **골드는 accent 전용, 전체 UI의 8% 이하.** 바탕 전체를 골드로 쓰지 않는다.
- **자산타입 색 = 단일 소스** `lib/asset-colors.ts`(어시 팔레트: 투자=골드·현금=세이지·부동산=올리브·크립토=코퍼·부채=테라코타). 도넛·리스트·drawer가 여기서 가져온다.
- primary(버튼·구조·텍스트) = 잉크(가독성). 골드는 secondary·accent·ring·차트·로고.

## 10. Form · Texture

- **Roundness = 4px**. 단단·정밀(큰 라운드 지양).
- **Blueprint 그리드** — 다크 배경에 은은한 격자(2~4% opacity). "축적=구조".
- **골드 오빗 아크** — 얇고 우아한 골드 궤도선 + glow. 히어로·마케팅 1개 한정. "꾸준한 축적의 궤도".
- **글래스 3D 깊이** — 반투명 프로스트 글래스(blur·굴절·soft shadow). **히어로·마케팅 이목 요소 전용**. 데일리 앱 UI는 플랫.
- 그림자: 다크는 glow/rim, 라이트는 soft shadow 절제.

## 14. 랜딩 히어로 (Solid Modern 다크, 2026-07-08)

`VideoHeroLight` = 다크 영상 배경 + 좌측 카피.
- **배경** = 자체 제작 다크+골드 비주얼(Gemini 이미지 → Higgsfield i2v): 딥 포레스트에 투명 저장고로 골드 코인이 슈트를 타고 흘러 축적 = 북극성 시각화. **데스크톱=영상 모션**(`hero.mp4`, 2560 delogo·`hero-poster.jpg`) / **모바일=정지 이미지**(`hero-bg-mobile.jpg`, 저장고 중심 세로 crop). 워터마크 delogo 제거, `prefers-reduced-motion` 시 pause.
- **좌측 카피**: eyebrow(골드) → H1 「복잡한 투자, **단순하게**」(골드 강조·언더라인) → 서브 한 줄 → 골드 CTA. 데스크톱=좌측 forest 워시, 모바일=저장고 위·텍스트 하단 앵커(하단 스크림).
- 밝은 배경 절대 금지(지난 라이트 영상이 다크 랜딩과 안 맞았던 원인) — 히어로 소스는 딥 포레스트 + 골드만. 워크플로우: [[reference_higgsfield_video_workflow]] / `docs/design/hero-explorations.md`.

## 15. Do / Don't

**Do** — 숫자를 가장 크게(tabular) · 골드는 accent(8%↓) · 다크=마케팅/프로, 라이트=데일리 · blueprint·아크·글래스는 은은하게 한 번씩 · 자산색은 `lib/asset-colors` 단일 소스 · 로고는 골드 코인 유지 · reduced-motion 가드 · "돈Doc" 표기.

**Don't** — 골드를 바탕 전체로 · serif를 UI/KPI 숫자에(마케팅 헤드만) · 글래스 3D를 데일리 앱에 남발 · 큰 라운드로 친근하게 · 장식 모션·반짝임 · 로고를 텍스트로(골드 소실) · "돈독" 단독 사용 · 종목 추천·수익 표현.
