## 0. 한 줄 정체성

**Solid Modern** — 딥 포레스트 다크 + 강한 골드 + 숫자가 주인공. 대담하고 단단하고 요즘스럽다.

북극성 「**복잡한 투자, 단순하게**」(= 여유자금을 단단한 자산으로 꾸준히 축적, 수익 아님)를 시각으로 번역: 화면은 조용하고 단단하되, **자산 숫자와 골드 궤도**가 "꾸준히 쌓인다"를 증명한다.

계보: Citium Wealth(다크그린+골드+오빗 아크·프리미엄) 팔레트 + Montera(글래스 3D 깊이·숫자/소셜프루프 히어로) 에너지 + Arc/Vercel/Bloomberg(단단한 tool·고대비)의 합성.

---

## 1. 정체성 3요소

1. **숫자가 히어로** — 순자산·자산 숫자가 모든 화면의 주인공. 가장 크게, tabular로, 흔들림 없이. "자산=주인공."
2. **단단·꾸준 > 반짝·hype** — 고대비·솔리드·차분. 재테크 hype 미감 배제. 움직임은 "쌓임/궤도"로만.
3. **대담한 단순함** — 과감한 여백·초점 하나·짧은 카피. 요소를 줄이되 브랜드 앵커(골드)는 남긴다.

---

## 2. 컬러 — 듀얼 모드

정체성은 하나, 모드는 둘. **랜딩·마케팅·공모주(프로암) = 다크 우선 / 데일리 앱(대시보드·현금흐름) = 라이트 기본(+다크 옵션).**

### 다크 (마케팅·프로 표면)
| 토큰 | 값 | 용도 |
|---|---|---|
| `surface-base` | `#182A24` | 딥 포레스트/네이비 바탕 |
| `surface-panel` | `#1F2E28` | 카드·패널(base 위 한 톤) |
| `surface-raised` | `#26362F` | 떠 있는 요소·호버 |
| `ink` | `#F4F1E9` | 본문 텍스트(웜 화이트) |
| `ink-dim` | `rgba(244,241,233,0.62)` | 보조 텍스트 |
| `hairline` | `rgba(201,165,74,0.18)` | 골드 hairline·구분선 |
| **`gold`** | **`#C9A54A`** | **accent·CTA·숫자 강조·차트 라인** |
| `gold-soft` | `rgba(201,165,74,0.12)` | 골드 배경 틴트 |

### 라이트 (데일리 앱)
| 토큰 | 값 | 용도 |
|---|---|---|
| `surface-base` | `#F5F3EE` | 하이키 페이퍼 |
| `surface-panel` | `#FFFFFF` | 카드 |
| `ink` | `#182A24` | 본문(딥 포레스트 잉크) |
| `ink-dim` | `rgba(24,42,36,0.60)` | 보조 |
| `hairline` | `rgba(24,42,36,0.10)` | 구분선 |
| **`gold`** | **`#B88A2A`** | **라이트 대비 확보한 진한 골드** |

### 시맨틱 (양 모드 공통, 톤만 조정)
- **상승·수입** = gold(강조) 또는 `#4E7A5F`(세이지, 중립 상승). 남용 금지 — 숫자 자체가 주인공이라 색은 절제.
- **하락·지출** = `#C0553D`(웜 테라코타). 빨강 hype 배제.
- **골드는 accent 전용** — 전체 UI의 8% 이하. 바탕 전체를 골드로 쓰지 않는다.

> 계승: 기존 포레스트 그린(#2F5D4F)은 surface 계열(딥 포레스트)로 흡수, accent 주역은 **골드로 승격**. 라이트 정체성의 세이지는 중립 상승 시맨틱으로 잔존.

## 3. 타이포그래피

| 역할 | 폰트 | 비고 |
|---|---|---|
| 헤드라인(영문) | **Space Grotesk** | 대담·기술적·모던. 라틴 display |
| 헤드라인·본문(한글) | **Pretendard** | 한글 UI 전 영역. 볼드 헤드라인도 Pretendard |
| 숫자(히어로·표) | **tabular** (Space Grotesk / Pretendard tabular) | 순자산·자산 숫자는 항상 고정폭. 정렬=신뢰 |
| 에디토리얼 세리프(선택) | Noto Serif KR / 라틴 세리프 | **특정 마케팅 헤드·인용에만 한정.** UI·본문·KPI엔 쓰지 않음(Citium 럭셔리감 소량 차용) |

> **A′ 규칙 변경**: 구 가이드는 "표지 KPI 숫자에 serif"였으나, Solid Modern에선 **숫자 히어로 = tabular 그로테스크**로 통일(숫자의 주인공성은 크기·고정폭·골드로 확보). 세리프는 KPI에서 내리고 마케팅 에디토리얼 액센트로 재배치.

---

## 4. 형태·질감

- **Roundness = 4px** (ROUND_FOUR). 단단·정밀. 큰 라운드(친근) 지양.
- **Blueprint 그리드** — 다크 배경에 아주 은은한 격자 텍스처. "축적=구조"의 바탕. 절대 튀지 않게(2~4% opacity).
- **골드 오빗 아크** — 얇고 우아한 골드 궤도선 + 미세 glow. 히어로·마케팅에서 "꾸준한 축적의 궤도" 모티프. 1개면 충분, 남발 금지.
- **글래스 3D 깊이** — 반투명 프로스트 글래스 코인/레이어 오브젝트(blur·굴절·soft shadow). **히어로·마케팅 이목 요소 전용**. 데일리 앱 UI는 플랫 유지(성능·가독성).
- 그림자: 다크는 glow/rim light 중심, 라이트는 soft shadow 절제.

---

## 5. 로고·골드

- 워드마크 = **골드 코인 wordmark**(`/logo-wordmark.svg`). 다크/라이트 각 버전.
- **골드가 나오는 자리를 사수** — 미니멀 nav라도 로고는 골드 코인 유지(랜딩에서 골드가 사라지지 않게).
- 로고 회전·변형·그림자 금지. "돈Doc" 표기 유지.

---

## 6. 숫자 히어로 원칙

- 순자산은 화면 최상단, 압도적 크기, tabular, 모드별 ink 색.
- 변동률(+2.4%)은 작은 배지로 곁에. 상승=골드/세이지, 하락=테라코타.
- 차트 라인 = **골드**. 채우기는 골드 그라디언트 소량. 축·그리드는 hairline.
- 표의 모든 금액 = tabular 정렬.

---

## 7. 모션

- `prefers-reduced-motion` 가드 필수(영상·아크 흐름·카운트업 정지).
- 허용 모션 = "쌓임/궤도"(아크 흐름, 숫자 카운트업 1회, 축적 애니메이션). 장식 모션·반짝임 금지.
- 히어로 영상: 다크+골드 톤으로 재제작 대상(현 라이트 영상은 데일리/라이트 표면에 잔존 가능).

## 8. Voice & Tone (유지)

| 상황 | 톤 | 예시 |
|---|---|---|
| Hero | Confident, 짧음 | "복잡한 투자, 단순하게." |
| 본문 | Clear, 존댓말, 단정 | "흩어진 자산을 한 화면에서 단단하게." |
| CTA | 동사, 간결 | "무료로 시작하기" |
| 빈 상태 | Warm | "아직 기록이 없어요." |

한국어 산출물은 Sunny 7규칙(번역체·군더더기 제거) 준수. 북극성 2층(우산=태도 / 하위=제품 설명) 유지.

---

## 9. 컴포넌트 패턴

- **카드**: surface-panel + hairline 보더 + roundness 4. 다크는 rim glow, 라이트는 soft shadow.
- **버튼(primary)**: 골드 solid + 어두운 텍스트, roundness 4~full. hover scale 1.03.
- **배지**: gold-soft 배경 + 골드 텍스트. 상태(매수/입금/배당/지출)는 시맨틱 색.
- **차트**: 골드 라인 + hairline 그리드. 도넛은 골드·세이지·ink 계열 절제 팔레트.
- **nav**: 로고 + 최소 액션(로그인·시작). 데드링크·군더더기 메뉴 금지.

---

## 10. Do / Don't

**Do** — 숫자를 가장 크게 · 골드는 accent(8%↓) · 다크=마케팅/프로, 라이트=데일리 · blueprint·아크·글래스는 은은하게 한 번씩 · tabular 정렬 · reduced-motion 가드.

**Don't** — 골드를 바탕 전체로 · 세리프를 UI/KPI에 · 글래스 3D를 데일리 앱에 남발 · 큰 라운드로 친근하게 · 장식 모션·반짝임 · 로고를 텍스트로(골드 소실).

## 11. 마이그레이션 계획

1. **랜딩(다크)** 먼저 — `VideoHeroLight`를 Solid Modern 다크로 재작업(합성 히어로 기준). 히어로 영상 다크+골드 재제작.
2. **토큰 레이어** — `tokens.ts` + `globals.css`에 듀얼모드 토큰 도입(다크/라이트 CSS 변수). 기존 라이트 앱은 라이트 토큰으로 무회귀 매핑.
3. **데일리 앱(라이트→듀얼)** — 대시보드부터 숫자 히어로·골드 차트·tabular 적용. 다크 옵션은 후순위.
4. **정본 승격** — 랜딩+토큰 착지 후 이 문서를 `BRAND_GUIDE.md`로 승격, 구 라이트 가이드는 `docs/archive/`.

> 원칙: 가이드↔코드 정합 유지. 이 문서가 코드보다 앞서므로, 각 표면이 실제로 옮겨질 때만 구 가이드 해당 절을 이 문서로 대체한다.
